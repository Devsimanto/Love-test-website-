# 💌 Secret Love Letter & Live Tracker Prank

একটি দ্বিভাষিক (বাংলা ও ইংরেজি) রোমান্টিক সিক্রেট প্রেমপত্র ও ২৫ বার "I love you" খোঁজার লুকোচুরি প্র্যাঙ্ক ওয়েব অ্যাপ্লিকেশন। এটি সরাসরি **GitHub Pages** বা যেকোনো স্ট্যাটিক হোস্টিংয়ে রান করার জন্য সম্পূর্ণ প্রস্তুত।

---

## ✨ কী কী নতুন ফিচার যোগ করা হয়েছে:
1. **বাংলা ও ইংরেজি সুইচ বাটন (Language Switcher):**
   - স্ক্রিনের উপরে `[ 🇧🇩 বাংলা | 🇬🇧 English ]` টগল বাটন দেওয়া হয়েছে। যেকোনো সময় এক ক্লিকে সম্পূর্ণ অ্যাপ বাংলা অথবা ইংরেজিতে পরিবর্তন করা যাবে।
2. **লজিক ও সিক্রেট বার্তা সম্পূর্ণ এনক্রিপ্টেড:**
   - চিঠির গোপন বার্তা ক্লাউড ডাটাবেজে এনক্রিপ্টেড অবস্থায় থাকে। ভিকটিম বা ব্রাউজারের ইনস্পেক্ট এলিমেন্ট (Inspect Element / DevTools) দিয়েও আসল চিঠি পড়া অসম্ভব।
   - কোডের ভেতরে ২৫ সংখ্যাটি সরাসরি না রেখে ওবফাসকেটেড লজিক রাখা হয়েছে যাতে ভিকটিম সোর্স কোড দেখে কোনো ক্লু না পায়।
   - ভিকটিমকে বিভ্রান্ত রাখতে লেখা থাকবে: **"⚠️ চিঠিটি আনলক হতে ১ থেকে ১০০০ বারও I love you তে চাপ দিতে হতে পারে!"**
   - প্রগ্রেস বার লাইন মুছে দেওয়া হয়েছে, যাতে ভিকটিম বুঝতে না পারে আর কতটুকু বাকি।
3. **১০০% সার্ভারলেস ফায়ারবেস ক্লাউড সিঙ্ক:**
   - কোনো Node.js সার্ভার ছাড়াই ব্রাউজার সরাসরি ফায়ারবেস ক্লাউড Firestore-এর সাথে সংযুক্ত।
   - আপনি GitHub Pages-এ হোস্ট করলেও ভিকটিমের প্রতিটি ক্লিক রিয়েল-টাইমে ফায়ারবেসে সেভ হবে এবং এডমিনের কাছে সরাসরি পৌঁছাবে!

## 🚀 গিটহাব পেজে হোস্ট করার সহজ নিয়ম (GitHub Pages Setup):

যেহেতু অ্যাপটি সম্পূর্ণ স্ট্যাটিক ওয়েব বান্ডেল হিসেবে তৈরি হয়েছে, তাই এটি গিটহাবে হোস্ট করা সবচেয়ে সহজ:

### ধাপ ১: গিটহাব রিপোজিটরি তৈরি
1. আপনার GitHub অ্যাকাউন্টে যান এবং **New Repository** তৈরি করুন (যেমন: `love-letter-prank`).
2. রিপোজিটরির টাইপ **Public** রাখুন।

### ধাপ ২: ফাইল আপলোড
আপনার প্রজেক্টের সব ফাইল (অথবা শুধু `dist` ফোল্ডারের ভেতরের ফাইলগুলো) রিপোজিটরিতে পুশ বা আপলোড করুন:
```bash
git init
git add .
git commit -m "Initial love prank app"
git branch -M main
git remote add origin https://github.com/<আপনার-ইউজারনেম>/<রিপো-নেম>.git
git push -u origin main
```

*(যদি আপনি পুরো প্রজেক্ট পুশ করেন, তাহলে `npm run build` দিয়ে তৈরি হওয়া `dist` ফোল্ডারটিকে গিটহাব পেজে ডেপ্লয় করতে পারেন অথবা `dist` ফোল্ডারের ভেতরের `index.html` ও `assets` ফোল্ডার সরাসরি রিপোর মূল রুটে রেখে দিতে পারেন।)*

### ধাপ ৩: গিটহাব পেজ সক্রিয় করা
1. গিটহাব রিপোজিটরির **Settings** ট্যাবে যান।
2. বাম পাশের মেনু থেকে **Pages** এ ক্লিক করুন।
3. **Build and deployment > Branch** অপশনে `main` সিলেক্ট করুন এবং ফোল্ডার সিলেক্ট করুন `/ (root)` অথবা `/docs` (বা গিটহাব অ্যাকশনস)।
4. **Save** চাপুন।
5. ১-২ মিনিটের মধ্যে আপনার ফ্রি লাইভ লিংক পেয়ে যাবেন:
   👉 `https://<আপনার-ইউজারনেম>.github.io/<রিপো-নেম>/`
